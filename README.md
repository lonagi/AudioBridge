# AudioBridge

Звук Windows в наушниках Mac по локальной сети, а при желании и обратный путь: микрофон Mac как микрофон в Windows.

Mac-приложение принимает системный звук Windows и смешивает его со звуком macOS, поэтому в одних наушниках слышно оба компьютера. Отдельный режим передаёт выбранный микрофон Mac в Windows через виртуальный микрофон AudioRelay.

## Как это устроено

| Часть | Технологии | Что делает |
|---|---|---|
| `mac/` | Swift, AppKit, AVAudioEngine, Network.framework | Окно приёмника, воспроизведение, автопоиск, раздача обновлений Windows, захват микрофона |
| `windows/` | C#, .NET 8, NAudio.Wasapi, Windows Forms | Захват звука Windows (WASAPI loopback), значок в трее, автозапуск, самообновление, вывод микрофона Mac |

Порты в локальной сети:

| Порт | Назначение |
|---|---|
| UDP 49152 | Звук Windows в Mac, AES-256-GCM |
| UDP 49153 | Автопоиск Mac, HMAC-SHA256 |
| TCP 8765 | Ссылка на установщик, обновления Windows, управление и поток микрофона |

Подробности протоколов и проверок: [docs/BUILD.md](docs/BUILD.md).

## Требования

- Mac на Apple Silicon, macOS 13 или новее, Xcode Command Line Tools.
- .NET SDK 8 для сборки Windows-части (собирается прямо на Mac).
- Windows 10 или 11 x64. Для режима микрофона нужен установленный AudioRelay с драйвером Virtual Mic.
- Оба компьютера в одной локальной сети без изоляции клиентов.

## Сборка и установка

```bash
scripts/new-pairing.sh 192.168.1.20
```

Скрипт создаёт `connection.json` со случайным ключом пары. IP нужен только как подсказка: Windows находит Mac автопоиском.

```bash
scripts/build.sh --install
```

Скрипт собирает Mac-приложение и Windows-программу, кладёт архив Windows внутрь приложения, ставит его в `/Applications` и запускает. Если `connection.json` в папке нет, берётся ключ из уже установленного приложения, поэтому пересборка не ломает существующую пару.

На Windows: откройте ссылку из окна Mac-приложения, распакуйте `Windows-Audio.zip` и запустите `Install.cmd`. Дальнейшие обновления Windows ставятся кнопкой **Обновить Windows** в окне Mac.

## Безопасность

- `connection.json`, собранное приложение и `Windows-Audio.zip` содержат личный ключ пары. Они в `.gitignore`, не публикуйте их.
- Ссылка на установщик отдаёт ключ по обычному HTTP. Пользуйтесь ей только в доверенной сети. Если ссылка утекла, создайте новую пару.

## AudioRelay

Режим микрофона пишет звук в драйвер AudioRelay Virtual Mic, который пользователь ставит сам вместе с AudioRelay. Проект не связан с AudioRelay, не распространяет его драйверы и проверялся с AudioRelay 0.27.5 (драйвер 1.0.2). Без AudioRelay работает всё, кроме микрофона.
