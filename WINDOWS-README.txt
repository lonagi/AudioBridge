# AudioBridge 0.4.2 — Mac ↔ Windows

Звук Windows слышен в наушниках Mac вместе со звуком macOS. Отдельный режим передаёт выбранный микрофон Mac в Windows.

## Микрофон

В окне Mac или в меню AudioBridge возле часов Windows:

1. Выберите **HyperX QuadCast S** или **Микрофон MacBook Pro**.
2. Нажмите **Включить микрофон**.
3. Для остановки нажмите **Выключить микрофон**.

На Windows ничего выбирать в AudioBridge не нужно: используется установленный **Virtual Mic (Virtual Mic for AudioRelay)**. Steam и Virtual Speakers не используются. Во время передачи AudioBridge выбирает этот вход как обычный микрофон и микрофон связи по умолчанию. В игре, браузере или программе звонков используйте вход **По умолчанию**. Приложение, в котором вручную закреплён другой микрофон, нужно один раз переключить на «По умолчанию» либо «Virtual Mic (Virtual Mic for AudioRelay)»; некоторые приложения требуют переподключить звонок.

Индикатор в секции микрофона на Mac показывает сигнал, прочитанный из виртуального микрофона Windows. При первом включении macOS запросит доступ к микрофону. AirPods и другие устройства не предлагаются как источник.

После запуска или перезапуска любой стороны режим выключен. Переключение HyperX / MacBook во время передачи применяется на обеих сторонах. При потере связи микрофон отключается; включите его снова после восстановления связи.

Обычное выключение режима и пункт **Выход** в трее возвращают прежние входы Windows. Если вы изменили вход вручную во время работы, программа сохранит ваш выбор. После принудительного «Снять задачу» возврат выполняется при следующем запуске AudioBridge; до этого Windows может оставить виртуальный микрофон выбранным.

Используется уже установленный драйвер AudioRelay Virtual Mic 1.0.2 из AudioRelay 0.27.5. AudioBridge не устанавливает, не изменяет и не распространяет драйвер. Другие версии требуют проверки совместимости. Не запускайте параллельно передачу другого источника в тот же микрофон через AudioRelay.

## Запуск и установка

**Mac:** AudioBridge находится в `/Applications`, доступен в общей сетке приложений. Запустите его для приёма звука Windows. Закрытие окна завершает приёмник, если других окон нет.

**Windows:** распакуйте `Windows-Audio.zip` полностью и запустите `Install.cmd`. Права администратора для AudioBridge не нужны. Файлы устанавливаются в `%LOCALAPPDATA%\AudioBridge`; рядом с часами появится значок. Ярлык AudioBridge доступен в Пуск. Виртуальный драйвер уже должен быть установлен отдельно.

Автозапуск происходит при входе в вашу учётную запись. Управление: Диспетчер задач → Автозагрузка приложений → AudioBridge. Отключение автозапуска не завершает текущий процесс. Для завершения используйте **Выход** в трее. Пункт **Приостановить звук** управляет только звуком Windows → Mac, микрофон имеет отдельную кнопку.

## Обновление и сеть

Нажмите **Обновить Windows** на Mac или **Проверить обновление** в трее Windows. Новая сборка скачивается с вашего Mac, проверяется и устанавливается с перезапуском. После обновления звук Windows подключается автоматически; микрофон остаётся выключенным. Настройка автозапуска сохраняется.

Оба компьютера должны быть в одной доступной локальной сети. IP-адреса определяются автоматически и могут меняться. После сна или смены сети поиск возобновляется. Изоляция клиентов роутера, VPN и блокировка портов могут мешать подключению.

Для первоначальной установки ссылка на архив показана в окне Mac. Обновление не скачивает произвольные программы из интернета: оно использует Windows-сборку, включённую в ваше Mac-приложение.

## Диагностика

Захватывается общий звук основного выхода Windows. Приложения с отдельно выбранным выходом или эксклюзивным аудио могут не попадать в поток.

Журнал Windows: `%LOCALAPPDATA%\AudioBridge\status.log`, доступен из трея. Звук в файлы не записывается. Проверка виртуального входа считывает только тот же передаваемый микрофон во время включённого режима.

UDP 49152 — звук Windows → Mac; UDP 49153 — поиск; TCP 8765 — обновления, управление и микрофон по исходящему соединению Windows. Аудио защищено AES-GCM, управление и поиск — HMAC-SHA256. Архив содержит ключ пары: не публикуйте его. Ссылка установки предназначена для доверенной локальной сети.
